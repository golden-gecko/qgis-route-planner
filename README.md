# qgis-route-planner

A lightweight QGIS plugin for planning and managing routes inside QGIS.

## Features

- Create and edit waypoint-based routes on the map.
- Compute and visualize simple routes using local network data.
- Import and export standard route formats (e.g., GPX).

## Intended use

Designed to simplify route creation and basic route analysis directly within QGIS (3.x). Suitable for field planning, small-scale route design, and exporting to navigation devices.

## Supported path-finding APIs

- Google Directions API — Commercial routing service (API key required).
- GraphHopper — Routing and optimization via HTTP API.
- Mapbox Directions API — Commercial directions API (requires access token).
